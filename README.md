A make.fun bounty entry: a program that writes the funniest single-line safety
warning label that should come printed on every human being — 160 characters
or fewer — to `/output/entry.txt`.

Run it with Node 22 or later:

```sh
node main.ts
```

The entry line:

> WARNING: This human will ignore every warning label, including this one, then blame the label for not warning them loudly enough.

See the competition on [make.fun](https://make.fun/c/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85).
